# The Last Ship v101

Apply over v100. Only changed files are supplied.

Crew names now use a built-in CRT keyboard. Tap a name field, enter letters/numbers with space, case toggle, backspace and clear, then Done or Next. Read-only fields prevent the native iPad keyboard opening. Each name allows up to 24 characters. Male/female capture voices now switch with a matching CRT push button; selections and names survive roster redraws, sound toggles and Field Manual use.

The blue and green gravity-well cores now emit brighter colour and a soft glow above the darkness mask. Their existing inner rotation remains; gravel and outer rocks remain stationary. Hidden wells stay hidden.

During the final stand, the staging platform and fixed ramp draw beneath Marines, aliens and sentry drones. The departing ship stays above the characters. All gunfire, alien death, ship, blackout and orbital audio timings are unchanged.
