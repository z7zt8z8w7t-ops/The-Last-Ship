# The Last Ship v102

Apply over v101. Only changed files are supplied.

Pressing Launch on the staging area automatically boards the caller before quarantine opens. This also allows the caller to be the first passenger if both scientists are already aboard.

At zero hours, both scientists plus at least one boarded, non-captive Marine trigger quarantine instead of immediate mission failure. The crew still chooses clearance/contamination and confirms departure. Missing either requirement retains the mission-failure outcome.

Once departure is confirmed, every Marine outside the departing passenger manifest moves to the staging area for the final battle, including captive Marines. If everyone escapes, the existing two-drone fallback remains.

The roster power-on flicker runs on initial display, rather than restarting for each name/voice/key update. The keyboard has a rare short CRT disturbance on a persistent clock with a random initial phase; reduced-motion mode disables it.

A flare permanently discovers its landing tile. Its normal glow, lure and burn-out rules remain unchanged. No item is searched or event triggered merely by illuminating a tile.

Seated initials in the APC and dropship now have small rings matching each player’s colour. Dropship seats have slightly wider spacing so the rings stay distinct.

All battle timings and all 33 embedded audio payloads are unchanged.
